# 智慧生态大棚 · Smart Ecological Farm

基于 **STM32F103C8T6** 的温室大棚自动控制系统。整套固件为标准外设库（StdPeriph）裸机工程，
无 RTOS，主循环 + 中断标志的非阻塞状态机结构，单个 Keil MDK5 工程即可编译。

支持两类上位机：**串口屏（Nextion）** 与 **语音识别模块**，另保留 **HC-05 蓝牙** 作为调试/遥控通道。

两个版本除下列 3 个文件外完全一致：

```

```

## 串口指令协议

发送格式：

```
@ + 指令内容 + 结束符
```

- **必须以 `@` 开头**，否则整帧丢弃
- 结束符：v1.0 只认 `\r\n`；**v1.1 认 `\r`、`\n`、`/` 任一**
- 开机处于**锁定态**，除 `@start` / `@stop` 外所有指令都会被拒绝，必须先解锁

| 指令 | 示例 | 作用 | 跳转页 |
| :-- | :-- | :-- | :-- |
| 解锁 | `@start` | 授权，之后指令才生效 | 0 |
| 急停 | `@stop` | 停泵 / 风扇 / 窗帘 / 灯，回到锁定态 | — |
| 切页 | `@PAGE=0` | 0 环境 / 1 水位与流量 / 2 执行器 / 3 通信记录 | — |
| 水泵 | `@PUMP=0`~`@PUMP=3` | 0 停 / 1 低 20% / 2 中 35% / 3 高 45% | 1 |
| 自动补水 | `@horizon=60` | 补到目标水位后自动停泵 | 1 |
| 风扇 | `@FENG=50` | 0~100 占空比 | 2 |
| 舱门 | `@Angle=0`~`@Angle=180` | 0=开门，>70=关门 | 2 |
| 卷帘开 / 关 / 停 | `@KAI` / `@GUAN` / `@TING` | 定时行程结束后自动停 | 2 |
| 照明自适应 | `@Auto` | 按光照反比自动调光 | 0 |
| 照明手动 | `@Manu` | 解除光控 | 0 |
| 亮度档位 | `@Light=0`~`@Light=10` | 档位 ×10%，自动切手动 | 0 |
| 触发 / 解除警报 | `@warning` / `@safe` | 爆闪 3 s 后转呼吸灯 / 恢复原亮度 | — |
| 状态报告 | `@REFRESH` | 串口打印一份全量状态 | — |

**大小写敏感**：`PAGE=` `PUMP=` `FENG=` `REFRESH` `KAI` `GUAN` `TING` 全大写；`Angle=` `Light=` `Auto` `Manu` 首字母大写。

## 编译

1. Keil MDK 5 打开 `v1.0/Project.uvprojx` 或 `v1.1/Project.uvprojx`
2. `Project → Rebuild all target files`
3. 下载到 STM32F103C8 最小系统板

无第三方依赖包，标准外设库与启动文件均已包含在工程内。

> 仓库已排除 `Objects/`、`Listings/`、`*.uvguix.*` 等编译中间产物与本地配置，
> 首次编译需要完整 Rebuild。`keilkill.bat` 可一键清理中间文件。

## 已知限制

- **卷帘为开环时间定位**：靠主循环计拍数估算行程，没有限位开关或编码器，
  长期反复开合会累积位置误差；主循环被传感器读取阻塞时实际行程会略长于设定值。
- **v1.1 的 `USART1` 仍会周期性下发 15 条 Nextion 协议帧**（`Serial_SendScreen_*`）。
  接语音模块时这批二进制是噪声，如需纯净链路应将其注释或加编译开关。
- 温湿度显示为 `00` 时通常是 DHT11 未接或上电初始化失败，不是显示错误。

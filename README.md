# 🌿 STM32 智能生态/自动化控制系统 (Smart Control System)

![STM32](https://img.shields.io/badge/MCU-stm32f103c8t6-blue.svg)
![C](https://img.shields.io/badge/Language-C-green.svg)
![License](https://img.shields.io/badge/License-MIT-yellow.svg)

基于 stm32f103c8t6 微控制器的多功能智能自动化控制终端。项目集成了环境监测（温湿度、光照）、水路闭环控制（水流量计、超声波水位、水泵）、通风与遮阳控制（双电机卷帘、排气扇、舵机舱门）以及声光报警系统。支持 **OLED 本地 UI 显示**、**串口屏实时推流** 与 **蓝牙无线指令控制**。

## ✨ 核心技术亮点

- **⏱️ 全非阻塞式架构**：摒弃低效的 `Delay` 死循环，主循环采用 `10ms` 滴答心跳（Tick-based），所有电机运行、警报闪烁、闭环检测均采用异步状态机实现，极大提高了系统的实时性。
- **💧 闭环防抖储水控制**：结合 YF-S401 水流量计与超声波测距仪，支持目标水位设定（`@horizon=x`）。内置 **2秒防波浪抖动算法**，确保加水精准、安全。
- **🚨 异步警报系统**：收到警报指令后，LED 照明系统会立刻挂起环境光控逻辑，进入“3秒高频爆闪 -> 无缝转入平滑呼吸灯”的紧急视觉反馈模式。
- **⚡ 硬件资源极限压榨与解耦**：
  - `TIM1` (高级定时器)：独占服务于 YF-S401 水流量计，实现精准 1Hz (1秒) 脉冲流速结算。
  - `TIM2`：提供 1kHz 频率，专职服务于水泵、风扇、LED 的 PWM 平滑调速。
  - `TIM3` & `TIM4`：分别负责双卷帘电机的独立调速与舱门舵机的角度控制。

## 📡 蓝牙通讯指令集 (Command API)

系统通过 `USART3` 接收纯文本指令，并通过解析器统一处理。所有指令需带有 `@` 或直接发送关键字符串。

### 1. 系统与权限控制
* `@start`：系统解锁并启动。上电默认锁定，授权后开始读取传感器并工作。
* `@stop`：**紧急停机**。立即切断水泵、风扇，刹停卷帘电机，关闭灯光，打断所有自动化任务。
* `@PAGE=x` (x:0~3)：切换本地 OLED 显示页面（0:主页 1:水路页 2:通风页 3:日志页）。
* `@REFRESH`：强制请求状态报告，单片机回传全中文格式化数据。

### 2. 水路自动化控制
* `@PUMP=x` (x:0~3)：手动设置水泵档位（0:停, 1:低档, 2:中档, 3:高档）。
* `@horizon=x` (x:0~100)：**自动储水指令**。设定目标水位百分比。系统启动水泵并在水位达标且稳定维持 2 秒后自动停机。

### 3. 环境与照明控制
* `@Auto`：开启 LED 自动光控模式（根据环境光强反相补偿亮度）。
* `@Manu`：开启 LED 手动模式。
* `@Light=x` (x:0~10)：手动设定 LED 亮度等级（1档 = 10% 亮度）。
* `@FENG=x` (x:0~100)：设定排气扇转速百分比。
* `@warning`：**触发警报**。LED 执行 3秒高频爆闪后转入呼吸灯模式。
* `@safe`：**解除警报**。恢复警报前的 LED 亮度和模式。

### 4. 机械结构控制
* `@Angle=x` (x:0~180)：控制舱门舵机角度（0度开门，>70度关门）。
* `@LEFT=x` / `@RIGHT=x` (x:0~100)：分别独立调节左右卷帘电机的转速。
* `@KAI`：自动开启窗帘（双电机同时顺时针运行 2.7 秒后自动停止）。
* `@GUAN`：自动关闭窗帘（双电机同时逆时针运行 2.7 秒后自动停止）。
* `@TING`：窗帘紧急刹车。

## 📂 核心代码结构说明

* `show.c` / `show.h`：核心业务逻辑层。包含 UI 刷新、传感器数据整合、字符串指令解析 (`Show_ParseCommand`) 以及 10ms 非阻塞主循环任务分配 (`Show_MainLoop`)。
* `YFS401.c` / `YFS401.h`：水流量计底层驱动。利用外部中断 (`EXTI1`) 捕捉脉冲，利用硬件定时器 (`TIM1`) 进行滑动平均滤波与流速换算。
* `PWM_3.c` / `PWM_3.h`：大功率设备驱动层。配置 `TIM2` 输出 1kHz 高频 PWM 信号，平滑控制水泵、风扇和 LED。
* `BlindMotor.c`：双电机卷帘控制器。包含 H 桥逻辑控制与 `TIM3` 差速调速机制。

## 🚀 快速上手

1. **硬件连接**：严格按照上述 [硬件引脚分配表](#️-硬件引脚分配-pinout) 连接所有模块，**注意区分 3.3V、5V 和 12V 供电，切勿接错烧毁 MCU！**
2. **编译工程**：使用 Keil MDK 5 (或类似 STM32 IDE) 打开工程文件，确保包含 Standard Peripheral Library。
3. **烧录调试**：通过 ST-Link 或 DAP-Link 烧录程序。
4. **启动测试**：
   - 手机连接蓝牙模块（通常为 HC-05 或 JDY-31）。
   - 打开串口调试助手，发送 `@start` 解锁系统。
   - 发送 `@horizon=80` 测试闭环水泵。
   - 发送 `@warning` 测试警报功能。

# 🌿 STM32 智能生态大棚控制系统 (Smart Ecological Farm)

![STM32](https://img.shields.io/badge/MCU-STM32F103C8T6-blue.svg)
![C](https://img.shields.io/badge/Language-C-green.svg)
![Keil](https://img.shields.io/badge/IDE-Keil%20MDK5-orange.svg)
![License](https://img.shields.io/badge/License-MIT-yellow.svg)

基于 **STM32F103C8T6** 的多功能温室自动化控制终端。集成环境监测（温湿度、光照）、
水路闭环控制（流量计、超声波水位、水泵）、通风与遮阳控制（双电机卷帘、排气扇、舵机舱门）
以及声光报警系统。支持 **OLED 本地 UI**、**串口屏实时推流** 与 **蓝牙 / 语音模块无线指令控制**。

标准外设库（StdPeriph）裸机工程，无 RTOS，单个 Keil 工程即可编译。

## ✨ 核心技术亮点

- **⏱️ 全非阻塞式架构**：摒弃 `Delay` 死循环，主循环采用 `10 ms` 滴答心跳（Tick-based），
  电机运行、警报闪烁、闭环检测全部为异步状态机，`Delay_ms(10)` 只用于节拍，不阻塞逻辑。
- **💧 闭环防抖储水控制**：结合 YF-S401 流量计与超声波测距，支持目标水位设定（`@horizon=x`）。
  内置 **2 秒防波浪抖动算法**——水位达标后需连续稳定 2 秒才停泵，避免水面波动误触发。
- **🚨 异步警报系统**：收到警报指令后 LED 立刻挂起环境光控，进入「3 秒高频爆闪 → 平滑呼吸灯」
  两段式紧急视觉反馈。
- **⚡ 外设资源解耦**：
  - `TIM1` (高级定时器)：独占服务 YF-S401，提供 1 Hz 流速结算时基
  - `TIM2`：`72 MHz ÷ 36 ÷ 100 = 20 kHz`，服务水泵、风扇、LED 三路 PWM 平滑调速
  - `TIM3` / `TIM4`：分别负责双卷帘电机的独立调速与舱门舵机角度控制
- **📟 双上位机并行**：`USART1` 走串口屏 / 语音模块，`USART3` 走蓝牙，两路指令共用同一套
  解析器与状态机，互不干扰。

## 📡 指令协议 (Command API)

### 帧格式

```
@ + 指令内容 + 结束符
```

- **必须以 `@` 开头**，否则整帧丢弃
- 结束符：**v1.0** 只认 `\r\n`；**v1.1** 认 `\r`、`\n`、`/` 任一
- 上电默认**锁定**，除 `@start` / `@stop` 外所有指令都会被拒绝

### 1. 系统与权限
| 指令 | 说明 |
| :-- | :-- |
| `@start` | 系统解锁并启动，之后指令才生效 |
| `@stop` | **紧急停机**：切泵、停扇、刹停卷帘、关灯，打断所有自动化任务 |
| `@PAGE=x` | 切换 OLED 页面（0 主页 / 1 水路 / 2 通风执行器 / 3 通信日志） |
| `@REFRESH` | 请求状态报告，回传全中文格式化数据 |

### 2. 水路控制
| 指令 | 说明 |
| :-- | :-- |
| `@PUMP=x` | 水泵档位（0 停 / 1 低 20% / 2 中 35% / 3 高 45%） |
| `@horizon=x` | **自动储水**（x: 0–100 目标水位 %），达标且稳定 2 秒后自动停泵 |

### 3. 环境与照明
| 指令 | 说明 |
| :-- | :-- |
| `@Auto` | LED 自动光控（按环境光强反相补偿亮度） |
| `@Manu` | LED 手动模式 |
| `@Light=x` | 手动亮度档位（x: 0–10，1 档 = 10%） |
| `@FENG=x` | 排气扇转速百分比（x: 0–100） |
| `@warning` | 触发警报：3 秒高频爆闪后转入呼吸灯 |
| `@safe` | 解除警报，恢复原亮度与模式 |

### 4. 机械结构
| 指令 | 说明 |
| :-- | :-- |
| `@Angle=x` | 舱门舵机角度（x: 0–180，0° 开门，>70° 关门） |
| `@KAI` | 开帘，行程到达后自动停止（v1.0 约 2.7 s，v1.1 约 4.5 s） |
| `@GUAN` | 关帘，同上 |
| `@TING` | 窗帘紧急刹车 |

**大小写敏感**：`PAGE=`、`PUMP=`、`FENG=`、`REFRESH`、`KAI`、`GUAN`、`TING` 需全大写；
`Angle=`、`Light=`、`Auto`、`Manu` 为首字母大写。

## 🚀 快速上手

1. **硬件连接**：按上表接线，**注意区分 3.3 V / 5 V / 12 V，切勿接错烧毁 MCU**
2. **编译**：Keil MDK5 打开 `v1.0/Project.uvprojx` 或 `v1.1/Project.uvprojx`，
   `Project → Rebuild all target files`（仓库已排除编译中间产物，首次必须 Rebuild）
3. **烧录**：ST-Link / DAP-Link 下载到 STM32F103C8 最小系统板
4. **启动测试**
   - 手机连接蓝牙 HC-05（默认 9600），或直接接串口到 `PA9/PA10`
   - 发送 `@start` 解锁 → 屏幕进入主页
   - 发送 `@horizon=80` 测试闭环补水
   - 发送 `@warning` 测试警报，`@safe` 解除

## ⚠️ 已知限制

- **卷帘为开环时间定位**：靠主循环计拍数估算行程，没有限位开关或编码器。长期反复开合会
  累积位置误差；主循环被传感器读取阻塞时，实际行程会略长于设定值。
- **v1.1 的 `USART1` 仍会周期性下发 15 条 Nextion 协议帧**（`Serial_SendScreen_*`）。
  接语音模块时这批二进制是噪声，需要纯净链路时应将其注释或加编译开关。
- 温湿度显示 `00` 通常是 DHT11 未接或上电初始化失败，不是显示错误。
- 中文字符串回显写死走 `USART3`；蓝牙未接时回显不可见。
